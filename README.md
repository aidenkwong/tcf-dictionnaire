# Dictionnaire TCF Canada

121 high-frequency vocabulary words for the TCF Canada French exam, ranked from most to least common.

**Live site:** https://aidenkwong.github.io/tcf-dictionnaire/

- Listen to every word, example sentence and linking phrase in standard French
- English translation under each example (can be hidden for self-testing)
- Search in French or English, filter by tier or topic
- Tick off words you've learned (saved in your browser)

The ranking is an estimate based on everyday French frequency and how often each topic appears on the exam. There is no official TCF Canada word list.

Audio recorded with ElevenLabs (voice: Benjamin).
